# SmartCampus AI Copilot Agent Guide

This repository is an FDE / AI Application Engineer interview project.

1. Read `README.md` and inspect the project structure before changing code.
2. Understand and preserve the existing architecture.
3. Do not introduce dependencies without a concrete need.
4. Keep the backend API, service, repository, and persistence layers separated.
5. Structured business data belongs in PostgreSQL.
6. Unstructured knowledge belongs in Qdrant.
7. Never put all business data into the vector database.
8. After changes, run every available lint, typecheck, test, and build command.
9. Review `git diff` before handing work off.
10. Never claim completion when validation is failing.
